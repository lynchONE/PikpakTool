# 验证说明

## 自动化验证

在项目根目录运行：

```powershell
npm ci
npm test
npm run build
```

测试覆盖：精确大小与年份边界、同名保留规则、部分失败保护、有限并发、批量 API 参数、完整本地 HTTP 流程、IndexedDB 升级与持久化、暂停后重新连接恢复、未知结果不重发、目录层级与再次判空，以及跨站/会话隔离检查。

测试中的令牌、文件名和网盘数据均为合成数据，不包含真实凭据或用户网盘导出。

## 性能基准

`npm run benchmark` 使用模拟接口延迟对比串行与并发执行，不访问真实网盘。其结果不能作为实际网络或网盘限流环境的固定性能承诺。

## 真实环境验收

- 在隔离的测试账号或专用测试文件中核对添加时间与大小。
- 检查批次完成后的移动、回收站和空目录结果。
- 暂停后重新连接，确认已完成批次不重发，未完成批次可恢复。
- 分别检查桌面和窄屏下的进度、列表、确认及恢复入口。

仓库分离时，已有本地读取的用户反馈及自动化验证；此说明不代表已针对所有账号、接口版本或浏览器完成真实写操作验收。
